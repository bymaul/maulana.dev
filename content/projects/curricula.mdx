This offline-first resume builder provides a private and streamlined way to create, edit, and export professional resumes without relying on external servers or an active internet connection. Built with Next.js, Tailwind CSS, shadcn/ui, Zustand, and PWA technologies, it combines a clean Harvard-style template with ATS-friendly formatting, real-time editing, local auto-saving, and JSON import/export to keep resume data fully under the user's control. With responsive editing tools, accurate print and PDF scaling, and installable desktop and mobile support, the application delivers a seamless resume-building experience while keeping everything fast, private, and accessible offline.
