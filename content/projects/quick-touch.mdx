Quick Touch turns the VS Code command palette into a file manager. One input creates a file, a nested path, a directory, or a whole batch such as `api.ts, types.ts, utils/`, and missing parent folders are built along the way, with a shared base path so `components/, Button.tsx` lands inside the folder. Rename, move, and delete work the same way through the prefixes `rn `, `mv `, and `del `, and delete goes to the OS trash rather than removing anything outright, since create, rename, and move all refuse to overwrite. Navigation is part of it too: `/` jumps to the workspace root, `..` goes up a level, and `~` reaches your home directory, with fuzzy filtering as you type. It ships bound to `ctrl+alt+n`, has no runtime dependencies, and goes through `vscode.workspace.fs` rather than Node's `fs`, so it behaves the same over remote and virtual workspaces.
